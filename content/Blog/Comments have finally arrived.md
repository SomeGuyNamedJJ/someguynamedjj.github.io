Hey everyone, it's been a while, but comments are finally here! I've also got some updates on projects I have already announced and new projects in development.

# Comments

You can now go to the bottom of certain pages[^1] and view comments people have made on the page. You will also be able to view and leave reactions on the page. These comments are powered by [giscus](https://giscus.app).

[^1]: Comments will be included on all Blog Posts released after this one. Alongside that, they may be avaliable in some projects regardless of their release date. There is no plan to implement comments on previous blog posts at this time.

Comments are an incredibly useful feature that allow you to send feedback directly on my site without having to [send me an email](https://to.1nteresting.name/email) (which you can still do anyway!).

Note that, before posting a comment or reaction, you will need to link giscus to your GitHub account. You do not need to do this to view comments or reactions, but it is a requirement to post them. I **do not** recieve access to your GitHub account in any way, it is only given to the giscus app, which only uses it to comment on GitHub discussions on your behalf.

Also to note, there is a notice below comments for now saying that they are experimental. This is not at the fault of the giscus developers, it is something placed there by me because of how I handle comments. There is a large CSS file used to theme the comments section, but I have been unable to test all features at this time. Due to this, I have marked comments as experimental. In the future, this will be removed.

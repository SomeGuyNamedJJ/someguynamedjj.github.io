Over the last few days, I've pushed some major updates to this website, alongside introducing this blog!

# Better linking, in multiple places
I've made multiple improvements to links included on this site, with any link not embedded into text taking the format that was previously exclusive to the footer, but has now been adjusted for everywhere across the site.

Alongside this, I have made updates to my [Links page](/Links.md) to have a much nicer interface with big buttons that expand on hovering. It's also reactive, so it will automatically optimise itself for your screen size. Links will also open in a new tab from there now.

These changes have also been applied retroactively to many pages, including those of inactive projects.

# Tags, tags tags!
I've taken the opportunity to introduce a lot of new tags for different pages. Some of these tags are Website, Minecraft, Datapacks, Resourcepacks, Python, Script, Discord and Pycord.

# Generative AI disclosures
I have added a page that details my stance on Generative AI and shows how I will disclose AI-generated content going forward. You can read that [here](/Stance-on-Generative-AI.md) or by clicking the 'Stance on Generative AI' button in the page footer at any time.

# Blog Introduction
The most obvious change is the introduction of this Blog, which I will post random stuff on every once in a while, and will also post a full transcript of any YouTube videos I produce, alongside additional notes not found in the original video or the video description. If a video has a corresponding blog post, there will be a link in the description, and the blog post will also embed the video.

# Technical Changes
Alongside these noticeable changes, various internal features have been tweaked, such as Quartz updating to v4.5.2, which brings bug-fixes and minor graphical changes.

# Future Plans
I have a ton of future plans for this site, and I'll share some of them here, but you'll just have to wait to see others.

## RSS Feeds
One of the things I really want to implement is RSS Feeds for this blog. I've heard that Quartz supports these, but I am unsure whether it does exactly what I want, as it might not allow me to make different feeds for different combinations of tags.

## Comments on Blog Posts
Another feature I'd like to add to Blog Posts is the ability to comment. If this was to be added, it would require a GitHub login, as I'd be using giscus, which is integrated with Quartz.

## A 'Backlog'
Some kind of page that displays the games I want to play, have played, have beat and have 100% (and how many times) would be very nice, but I would have to not only create all of the elements for it, but I'd have to scour my game library, find a ton of cover art, and then compile it all together on one massive page. It does sound cool, but it might be a while.

## Custom Page Themes
Most pages on this site generally follow the same theme, but I have a plan to implement custom themes for some Project pages, in fact, I've already got a mockup for a project that should be coming soon, and it looks pretty good. I plan to have most projects releasing from now to have a custom site theme that applies to the page content.

Anyway, I'm excited for the future of this site and the projects that are in the works, and can't wait to announce them.

*that is all*

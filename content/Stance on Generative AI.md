Generative AI is quite a contested topic on the internet, and in this page I will detail my opinions on Generative AI and how I disclose content created by Generative AI.

I believe that Generative AI can be useful in some cases, but in most situations it can be harmful to everyone involved, other than AI companies' shareholders. It harms people's jobs, it harms the environment, and it can even harm users.

# AI-Generated Content Disclosures

For these reasons, I intend to always disclose any content that was created with the use of Generative AI. Depending on where the content is made avaliable, the disclosure will be slightly different.

> [!info] Old content may not have disclosures.
> AI-generated content disclosures for any content created by me only started after 2026-02-15. Any content released before this may be inconsistent on the method it discloses AI-generated content and whether it discloses it at all. Some content may have a disclosure added retroactively.

## 1nteresting.name
Content featured on this website will display a message stating whether AI-generated content is featured. An example of this message is shown below.

> [!warning] This project contains AI-Generated content
> Some content shown in this project may have been created with **Generative AI**.
> 
> The following Generative AI tools have been used:
> 
> - **Large Language Models have been used to generate portions of code used in this project.**
> - **Large Language Models have been used to generate portione of code used in this project's page.**
>
> See [My Stance on Generative AI](/Stance-on-Generative-AI) for more information.

A variant of this message will be displayed at the top of any page that uses Generative AI.

## YouTube
Content featured on my YouTube channel will always display a disclosure of whether Generative AI was used in that video in the description. An example of that disclosure when a video does not feature AI-generated content is shown below.

> This video does not feature any content created using Generative AI. See [https://to.1nteresting.name/ai](https://to.1nteresting.name/ai) for more information.

An example of that disclosure when a video does feature AI-generated content is shown below.

> This video features content created using Generative AI.
> 
> The following Generative AI tools have been used:
> 
> Large Language Models have been used to generate portions of code used in a project featured in this video.
> 
> See [https://to.1nteresting.name/ai](https://to.1nteresting.name/ai) for more information.

> [!info] 
> These disclosures will not be featured on unlisted speedrun videos, which will never use Generative AI.

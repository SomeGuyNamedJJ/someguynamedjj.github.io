# About this Project
This is a very simple website that displays all blocks featured in old versions of Minecraft. It doesn't display all versions of the game, but it goes from Alpha 1.0.17_04 to Release 1.5.2. More versions will be added in the future.

The point of this site is that players of older versions of Minecraft don't have a good way to view all blocks that can be used for building, which can get really annoying when you switch versions often.

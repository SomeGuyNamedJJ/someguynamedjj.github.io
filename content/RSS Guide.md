This site has a blog, which supports RSS Feeds. What this means is that if you have an RSS Reader application, or your device natively has RSS feed support, you can add my site's Blog there.

> [!warning] Some RSS Readers are inaccurate
> Some RSS Readers can be inaccurate and have issues displaying my Blog. Notable ones I have found to exhibit this are:
> 
> - Smart Launcher Feed
> 
> - RSS.app
>
> If you are using one of these readers and have issues, please **try a different reader** before reporting an issue.

# Add an RSS Feed

To do this, you will first have to navigate to your RSS Reader application and open the menu that allows you to add an RSS Feed. This can change depending on the application you are using.

When on this menu, if you are presented with preset options, you must select a button that allows you to add a Feed URL. Enter the URL corresponding to what you would like to follow (shown below) here. Depending on what reader you are using, my icon may be displayed here, if you see a different icon, make sure you get the correct URL. If you don't see an icon, your reader may just not display the icon.

You can now confirm that you are adding my RSS Feed, which should then appear in your RSS Reader. Just check to make sure it does appear, if not, try restarting your RSS Reader. If that does not work, try and add it again.
